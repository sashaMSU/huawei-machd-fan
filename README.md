# Управление вентиляторами Huawei MateBook X Pro 2021 (MACHD-WXX9)

Скрипт для Linux, который позволяет настроить охлаждение ноутбука под себя:
сделать вентиляторы тише при небольшой нагрузке, изменить температуры их
включения и разгона, ускорить снижение оборотов после нагрузки.

Скрипт меняет настройки штатного контроллера охлаждения — EC. Контроллер
по-прежнему сам регулирует вентиляторы. Перепрошивать BIOS не нужно;
лимиты мощности процессора и Turbo Boost программа не меняет.

[English](README.en.md) · [Все настройки и заводские значения](docs/defaults.md)

## Совместимость

Только **MACHD-WXX9**, плата **MACHD-WXX9-PCB**, **BIOS 1.67 / EC 1.67.0**.
Ревизия **PCB-B1 и другие модели не поддерживаются**. Не отключайте проверки
модели и версии ради запуска на другом ноутбуке.

Это экспериментальный проект, не программа Huawei. Пониженные обороты могут
повысить температуру и вызвать троттлинг. Скрипт **не останавливается при
перегреве** и не заменяет температурную защиту. После изменения настроек
проверьте температуры под нагрузкой и запуск обоих вентиляторов из остановки.

## Какие настройки установлены

В репозитории уже выбран профиль с более высокими температурными порогами
SEN1, меньшими минимальными оборотами и более быстрым снижением скорости:

| Параметр | Заводской | В этом профиле |
|---|---|---|
| SEN1: пороги ступеней | 47, 50, 54, 56, 60 °C | 52, 55, 59, 61, 65 °C |
| SEN1: цели `low/high` | 47 / 50 °C | 52 / 55 °C |
| SEN1: переключение `low/high` | 47 / 50 °C | 52 / 55 °C |
| SEN1: включение / выключение | 43 / 40 °C | 48 / 45 °C |
| Минимальная цель первого вентилятора | 4100 RPM | 3100 RPM |
| Изменение задания за расчёт EC: рост / снижение | 50 / 20 RPM | 50 / 60 RPM |

Остальные параметры оставлены заводскими. Полная таблица — в
[docs/defaults.md](docs/defaults.md). В этой версии `Ki` и `Kd` должны быть нулевыми.

## Установка

Нужны Linux, Python 3.10+ и модуль `acpi_call`. Для Ubuntu / Kubuntu выполните
из папки репозитория:

```bash
sudo apt install python3 acpi-call-dkms "linux-headers-$(uname -r)"
sudo modprobe acpi_call
python3 huawei_fan_table.py check
sudo python3 huawei_fan_table.py show
```

`check` проверяет настройки без обращения к ноутбуку, `show` читает состояние EC.
При ошибке проверки не переходите к запуску. Не используйте одновременно другие
программы, обращающиеся к `/proc/acpi/call`.

Сначала проверьте работу в терминале:

```bash
sudo python3 -u huawei_fan_table.py run
```

Для остановки нажмите **Ctrl+C** и дождитесь `factory_restored verified=true` —
подтверждения возврата заводских настроек.

Затем установите службу и включите автозапуск:

```bash
sudo bash install.sh
sudo systemctl enable --now huawei-fan.service
```

Установщик сам службу не запускает. При обновлении сначала остановите её,
перенесите свою `TABLE` в новый файл и установите его через
`sudo bash install.sh --replace`. Старую `huawei-fan-sleep.service`, если она
осталась от предыдущих версий, отключите и удалите: здесь она не используется.

## Как менять настройки

Редактируйте `TABLE` и `INTERVAL` в начале скрипта. `FACTORY` содержит заводские
значения для восстановления — её, адреса памяти и проверки менять не нужно.

Для установленной службы:

```bash
sudo systemctl stop huawei-fan.service
sudoedit /usr/local/lib/huawei-fan/huawei_fan_table.py
python3 /usr/local/lib/huawei-fan/huawei_fan_table.py check
sudo systemctl start huawei-fan.service
```

При `INTERVAL = 5` программа делает пятисекундную паузу между проверками таблицы
и заново применяет настройки, если они сбросились, в том числе после сна.
Это не частота управления вентиляторами: EC работает самостоятельно.
Изменения файла вступают в силу только после перезапуска программы.

`low/high` — температурные цели, а `step` — ступень ограничения оборотов,
**не команда держать фиксированную скорость**. Подробнее:
[как работает регулятор](docs/algorithm.md).

## Журнал

```bash
journalctl -u huawei-fan.service -f -o cat
```

Пример строки:

```text
mode=auto/low enabled=1 preset=1 step=1 rpm=3150/3060 target=3100 command=3100/2900 limit=5000 CPU_EC=59.2 SEN1=52.6 Charger=46.2 written=0
```

`rpm` — измеренные обороты, `target` — внутреннее задание первого вентилятора,
`command` — команды для обоих вентиляторов, `limit` — предел текущей ступени.
Температуры сглажены контроллером EC; `CPU_EC` не обязательно совпадает с `coretemp`.
`written=0` означает, что перезапись настроек не потребовалась.

## Остановка и удаление

Остановить службу и отключить автозапуск:

```bash
sudo systemctl disable --now huawei-fan.service
```

При обычной остановке скрипт пытается вернуть заводские настройки. Повторить
восстановление вручную, когда служба уже остановлена:

```bash
sudo python3 /usr/local/lib/huawei-fan/huawei_fan_table.py restore
```

При аварийном завершении восстановление не гарантировано. Перезагрузка также
не считается проверенным способом сброса. Перед переходом в Windows, если там
нужны заводские настройки, дождитесь `factory_restored verified=true`.

Для удаления выполните из папки репозитория:

```bash
sudo bash uninstall.sh
```

Если восстановление не удалось подтвердить, удаление прервётся.
